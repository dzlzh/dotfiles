# Herdr 快捷键

“前缀 + X”表示：先按 `Ctrl+B`，松开，再按后面的键。

### 通用操作

| 功能 | 快捷键 |
|---|---|
| 快捷键帮助 | 前缀 + `?` |
| 设置 | 前缀 + `Shift+S` |
| 分离 Herdr | 前缀 + `D` |
| 重新加载配置 | 前缀 + `R` |
| 打开通知对应目标 | 前缀 + `O` |
| 工作区选择器 | 前缀 + `W` |
| 进入导航模式 | 前缀 + `G` |

### 工作区

| 功能 | 快捷键 |
|---|---|
| 新建工作区 | 前缀 + `Shift+N` |
| 新建 Git worktree | 前缀 + `Shift+G` |
| 重命名工作区 | 前缀 + `Shift+W` |
| 关闭工作区 | 前缀 + `Shift+D` |
| 上一个工作区 | 前缀 + `Shift+H` |
| 下一个工作区 | 前缀 + `Shift+L` |

### Agent

| 功能 | 快捷键 |
|---|---|
| 上一个 Agent | 前缀 + `Shift+K` |
| 下一个 Agent | 前缀 + `Shift+J` |
| 选择第 1～9 个 Agent | 前缀 + `Alt+1～9` |

### 标签页

Herdr 标签页相当于 tmux 的窗口。

| 功能 | 快捷键 |
|---|---|
| 新建标签页 | 前缀 + `C` |
| 重命名标签页 | 前缀 + `Shift+T` |
| 上一个标签页 | 前缀 + `Ctrl+H` |
| 下一个标签页 | 前缀 + `Ctrl+L` |
| 切换到标签页 1～9 | 前缀 + `1～9` |
| 关闭标签页 | 前缀 + `Shift+X` |

### 面板与分屏

| 功能 | 快捷键 |
|---|---|
| 重命名面板 | 前缀 + `Shift+P` |
| 回滚/编辑终端历史 | 前缀 + `Esc` |
| 聚焦左侧面板 | 前缀 + `H` |
| 聚焦下方面板 | 前缀 + `J` |
| 聚焦上方面板 | 前缀 + `K` |
| 聚焦右侧面板 | 前缀 + `L` |
| 下一个面板 | 前缀 + `Tab` |
| 上一个面板 | 前缀 + `Shift+Tab` |
| 左右分屏 | 前缀 + `V` |
| 上下分屏 | 前缀 + `S` |
| 关闭面板 | 前缀 + `X` |
| 放大/还原面板 | 前缀 + `Z` |
| 进入尺寸调整模式 | 前缀 + `Shift+R` |
| 显示/隐藏侧边栏 | 前缀 + `T` |

### 导航模式

先按前缀 + `G`：

| 功能 | 按键 |
|---|---|
| 上一个工作区 | `↑` |
| 下一个工作区 | `↓` |
| 左侧面板 | `H` 或 `←` |
| 下方面板 | `J` |
| 上方面板 | `K` |
| 右侧面板 | `L` 或 `→` |

### 特殊快捷键

| 功能 | 快捷键 |
|---|---|
| 远程模式粘贴图片 | `Ctrl+V`，不需要前缀 |
| 将原始 `Ctrl+F` 发送给内部程序 | `Ctrl+F`，再按 `Ctrl+F` |
